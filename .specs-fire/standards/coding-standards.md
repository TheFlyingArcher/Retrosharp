## Conventions

- **Layering**: API/Engine → Service → Data → Domain. Contract entities never cross the API boundary; map to DTOs.
- **DI**: each project has an `IocRegistrations : IRegister`; `ContainerRegistration.RegisterContainer()` discovers them
- **Repositories** derive from `BaseRepository<TM, TC>`; project queries to the needed shape
- **Idempotency**: enforce via database unique indexes on natural keys and bulk inserts that skip existing rows
- **Imports**: keep dependency order (seed → people → game logs → play-by-play → standings)
- **Errors in engine**: classify via `ImportFailureClassifier`; unrecoverable failures skip retries
- **Front end**: standalone components, signals, lazily loaded routes; typed models in `src/model`, HTTP services in `src/service`

## Logging

- `Microsoft.Extensions.Logging` with structured message templates
- Never log secrets or connection strings

## Comments

- Comment the *why* (non-obvious decisions, Retrosheet data quirks), not the *what*
- Match the surrounding comment density
