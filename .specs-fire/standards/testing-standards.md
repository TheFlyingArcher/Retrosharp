# Testing Standards

## Overview

Backend uses xUnit; front end uses Vitest through the Angular CLI.

## Test Projects

| Project | Scope |
|---|---|
| `src/lib/Retrosharp.Format.Tests` | Retrosheet file formats, parsers, play-by-play, standings |
| `src/lib/Retrosharp.Service.Tests` | Services, statistics, import logic |
| `src/engine/Retrosharp.Engine.Console.Tests` | Sagas, recoverability policy, failure classifier |
| `src/ui/Retrosharp.UI.Web` | Component/service specs (`ng test`) |

## Coverage

- Collector: coverlet (`coverlet.collector`). No numeric gate is enforced.
- Critical paths that must be covered: play-code parsing and play-by-play state, rate-statistic calculations, import idempotency, standings computation, engine failure classification

## Conventions

- New behaviour and bug fixes ship with tests in the matching project
- Follow neighbouring test naming and structure
- Use real Retrosheet-shaped fixtures for parser tests; avoid mocking the parser itself

## Running Tests

```bash
# All .NET tests
dotnet test src/Retrosharp.slnx

# With coverage
dotnet test src/Retrosharp.slnx --collect:"XPlat Code Coverage"

# Single project
dotnet test src/lib/Retrosharp.Format.Tests

# Front end (from src/ui/Retrosharp.UI.Web)
npm test
```

## CI/CD

Not configured. Run the relevant tests locally before opening a PR.
