# Tech Stack

## Overview

Retrosharp is an n-tier .NET + Angular application backed by PostgreSQL, with long-running imports handled by NServiceBus sagas over RabbitMQ.

## Core Technologies

- **Language**: C# on .NET 10 (`net10.0`); TypeScript ~6.0 for the front end
- **API framework**: ASP.NET Core 10 MVC controllers with OpenAPI
- **Front end**: Angular 22 (standalone components, signals, lazy routes), Angular Material, Bootstrap 5
- **Messaging**: NServiceBus 10 with RabbitMQ transport (`NServiceBus.RabbitMQ`) and SQL persistence on PostgreSQL
- **Engine host**: .NET generic host with a small `/health` endpoint on port 8081

## Data Layer

- **Database**: PostgreSQL 16 (chosen over SQL Server for ARM64 / Raspberry Pi hosting)
- **ORM**: Entity Framework Core 10 + Npgsql, code-first; migrations run by `Retrosharp.Data.Migration`
- **Mapping**: Mapster (`ProjectToType<T>()` in repositories)
- **CSV parsing**: CsvHelper
- `DateTime` stored as `timestamp without time zone`

## API Layer

- REST/JSON, DTOs mapped from contract entities; spec in `spec/api.md`
- Auth: JWT bearer / Microsoft.Identity.Web wired but not enforced in Phase 1

## Infrastructure

- Docker + Docker Compose (`docker-compose.yml`, `docker-compose.pi.yml`)
- Services: postgres, rabbitmq (management UI 15672), migration, engine, api
- CI/CD: none configured

## Development Tools

- **Build**: `dotnet` CLI, solution `src/Retrosharp.slnx`; `ng` CLI for the front end
- **Package managers**: NuGet, npm
- **Formatter (front end)**: Prettier (`printWidth` 100, single quotes)
- **Tests**: xUnit (.NET), Vitest via `ng test` (front end)
